# A/B тестирование: анализ поведения пользователей e-commerce платформы

## О проекте

Статистический анализ поведения пользователей французского C2C fashion-маркетплейса.  
На основе данных ~99 000 пользователей проверяется ряд гипотез о факторах, связанных с покупательской активностью.

**Датасет:** [E-Commerce Users of a French C2C Fashion Store](https://www.kaggle.com/datasets/jmmvutu/ecommerce-users-of-a-french-c2c-fashion-store) (Kaggle, ~99k пользователей, 24 признака)

## Методология

**Бакетный t-тест** - пользователи разбиваются на 50 бакетов, сравниваются бакетные средние. Бакетирование приближает распределение к нормальному и снижает влияние выбросов.

**Тест Уэлча** (`equal_var=False`) - используется вместо стандартного t-теста, поскольку во всех гипотезах группы несбалансированы по размеру, а тест Левена фиксирует неравенство дисперсий. При таком сочетании стандартный t-тест завышает ошибку 1-го рода.

**Бутстреп верификация** - 1000 итераций с подвыборками равного размера. Если доля значимых тестов > 95% - результат считается устойчивым.

**Хи-квадрат** - для проверки связи между категориальными переменными.

**Уровень значимости:** α = 0.05

**Принятие решений:** На практике решение о раскатке фичи принимается на основе двух критериев: статистической значимости (p < α) и превышения MDE - минимального эффекта, интересного бизнесу. В данном проекте MDE не задавался ввиду отсутствия реального бизнес-контекста, решения принимаются только на основе статистических тестов.

## Результаты

### AA-тест
Случайный сплит всех пользователей 50/50 дал p-value = 0.29 - механизм сплитования работает корректно.

### AB-тесты

| Гипотеза | Среднее A | Среднее B | p-value | Бутстреп | Результат |
|---|---|---|---|---|---|
| Фото профиля -> покупки | 1.84 | 0.14 | <0.001 | 1.000 | H0 отвергнута, эффект обратный |
| Приложение -> покупки | 0.11 | 0.35 | <0.001 | 1.000 | H0 отвергнута |
| iOS vs Android | 0.36 | 0.37 | 0.781 | 0.005 | H0 не отвергнута |
| Подписки -> покупки | 0.10 | 1.97 | <0.001 | 1.000 | H0 отвергнута |
| Вишлист -> покупки | 0.05 | 1.33 | <0.001 | 1.000 | H0 отвергнута |

### Ключевые инсайты

- Пользователи с приложением покупают в 3 раза больше - установка приложения коррелирует с вовлеченностью
- Пользователи с вишлистом покупают в 25 раз больше - вишлист является сильным индикатором покупательского намерения
- Платформа (iOS vs Android) не влияет на покупательское поведение
- Пользователи без фото профиля покупают больше - вероятно, они являются покупателями, а пользователи с фото - продавцами

## Ограничения

1. **Данные не из реального эксперимента** - датасет представляет срез пользователей в один момент времени, а не результат контролируемого эксперимента. Из этого вытекают все остальные ограничения.

2. **Selection bias** - группы сформированы по признаку самовыбора пользователей, а не случайным назначением. Результаты показывают корреляцию, а не причинно-следственную связь.

3. **Несбалансированные группы** - в некоторых тестах группы сильно различаются по размеру.

4. **Сетевой эффект** - пользователи платформы взаимодействуют друг с другом (подписки, лайки, покупки). Группы потенциально влияют друг на друга, нарушая допущение о независимости. 

5. **нет проверки SRM** - проверка на несоответствие соотношения выборок применима только при контролируемом эксперименте с заранее заданным соотношением групп.

6. **Нормальность нарушена** - тест Шапиро-Уилка отвергает нормальность бакетных средних в большинстве групп. Результаты верифицированы бутстреп-методом, оба метода дают согласованные выводы.

7. **Детерминированное бакетирование** - бакеты формируются срезом с шагом, а не через хеширование user_id.
